## API Key Setup

### How to Get API Keys

#### OpenAI
1. Visit https://platform.openai.com/api-keys
2. Sign in or create account
3. Click "Create new secret key"
4. Copy key (starts with `sk-`)

#### Anthropic
1. Visit https://console.anthropic.com/settings/keys
2. Sign in or create account
3. Click "Create Key"
4. Copy key (starts with `sk-ant-`)

#### xAI
1. Visit https://console.x.ai/
2. Sign in with X/Twitter account
3. Navigate to API Keys
4. Generate new key

#### Google (Gemini)
1. Visit https://makersuite.google.com/app/apikey
2. Sign in with Google account
3. Click "Create API key"
4. Copy key

#### Meta (via Together AI)
1. Visit https://api.together.xyz/settings/api-keys
2. Sign up or sign in
3. Create new API key
4. Copy key

#### Mistral AI
1. Visit https://console.mistral.ai/api-keys/
2. Sign up or sign in
3. Create API key
4. Copy key

#### Cohere
1. Visit https://dashboard.cohere.com/api-keys
2. Sign up or sign in
3. Generate trial or production key
4. Copy key

#### Hugging Face 🆕
1. Visit https://huggingface.co/settings/tokens
2. Sign up or sign in
3. Click "New token"
4. Select "Read" access
5. Copy token (starts with `hf_`)

## Integration in ApexForge

### Adding API Keys
1. Navigate to **CEO Dashboard** → **Integrations Hub**
2. Select **AI Models** tab
3. Enter your API key for any provider
4. Click **Test** to validate
5. Status changes to ✓ Valid

### Model Selection
1. Go to **Generator** page
2. Click **AI Model Selector**
3. Filter by:
   - **Provider**: OpenAI, Anthropic, xAI, Google, Meta, Mistral, Cohere, Hugging Face
   - **Category**: Flagship, Fast, Mini, Code, Vision
4. Click models to select/deselect
5. Multiple models enable AI debate mode

### Using Multiple Models

## Technical Details

### API Endpoints
All models are integrated with proper API endpoints:
- OpenAI: `api.openai.com/v1/chat/completions`
- Anthropic: `api.anthropic.com/v1/messages`
- xAI: `api.x.ai/v1/chat/completions`
- Google: `generativelanguage.googleapis.com/v1beta`
- Meta: `api.together.xyz/v1/chat/completions`
- Mistral: `api.mistral.ai/v1/chat/completions`
- Cohere: `api.cohere.ai/v1/chat`
- Hugging Face: `api-inference.huggingface.co/models/{model}`

### Response Format
All models return standardized responses:
```typescript
{
  success: boolean
  content?: string
  error?: string
  model: string
  tokensUsed?: number
}
```

- Fallback to alternative models

## Troubleshooting

### Common Issues

**"No API keys configured"**
- Add at least one valid API key in Integrations Hub
- Test key to ensure it's valid

**"API error: 401"**
- API key is invalid or expired
- Regenerate key from provider dashboard

**"API error: 429"**
- Rate limit exceeded
- Wait a few minutes or upgrade plan

**"Model loading timeout"**
- Hugging Face inference API warming up
- Retry in 30 seconds
