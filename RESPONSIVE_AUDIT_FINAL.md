5. ✅ **Complex forms**: Progressive disclosure on mobile
6. ✅ **Large datasets**: Virtualization for performance
7. ✅ **Landscape mobile**: Handled with min-height
8. ✅ **Small tablets**: Treated as large mobile

## Responsive Utilities Reference

### CSS Classes
```css
/* Typography */
.text-responsive          /* Body text */
.text-responsive-sm       /* Small text */
.text-responsive-lg       /* Large text */
.heading-responsive       /* Main headings */
.heading-responsive-sm    /* Sub headings */

/* Interactive */
.btn-responsive           /* Buttons */
.input-responsive         /* Inputs */
.touch-target            /* Min 44×44px */
.interactive-hover        /* Hover scale */
.interactive-press        /* Press scale */
.interactive-full         /* Both states */

/* Spacing */
.spacing-responsive       /* Gaps */
.spacing-responsive-sm    /* Small gaps */
.spacing-responsive-lg    /* Large gaps */

/* Icons */
.icon-responsive          /* Standard icons */
.icon-responsive-sm       /* Small icons */
.icon-responsive-lg       /* Large icons */
```

### React Hooks
```typescript
import { useScreenSize } from '@/hooks/use-mobile'
import { useResponsiveSize } from '@/hooks/use-responsive-size'
import { useResponsiveFont } from '@/hooks/use-responsive-font'

// Screen detection
const { isMobile, isTablet, isDesktop } = useScreenSize()

// Responsive values
const { buttonSize, iconSize, spacing } = useResponsiveSize()

// Font sizing
const { fontSize, lineHeight, letterSpacing } = useResponsiveFont()
```

### Common Patterns
```tsx
// Grid layouts
<div className="grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-4 gap-4">

// Text sizing
<p className="text-responsive">

// Conditional rendering
{isMobile ? <MobileComponent /> : <DesktopComponent />}
```
