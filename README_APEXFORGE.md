## 🚀 Quick Start

This application is built with React (TypeScript) + Vite and is ready to use!

### Run the Application:
```bash
npm run dev
```

### Key Features:

#### The Forge
5 AI agents (GPT-4, Claude, Grok, Gemini, Llama) build your app with live debates. Watch them argue about security, design, performance, and more!

#### Fusion Mode
After generation, see 3 different versions (Fastest, Most Secure, Most Beautiful) and choose your favorite or mix and match features.

#### Live Deployment
Apps are instantly deployed with HTTPS and custom domains (simulated in testing mode).

#### FREE Idea Incubator
Generate 5 validated app ideas with wireframes, tech stacks, and revenue models - no credits used!

#### CEO Dashboard
Advanced analytics, business controls, and "Whisper Mode" for testing behavioral patterns.

## 🛠️ Tech Stack

### Frontend:
- React 19 + TypeScript
- Tailwind CSS 4
- Shadcn UI components (40+ preinstalled)
- Framer Motion for animations
- Phosphor Icons

### Charts & Analytics:
- Recharts for data visualization
- D3.js support

### Storage & Auth:
- Spark KV for persistence (via `useKV` hook)
- TOTP authentication (OTPAuth + QRCode)
- Magic link authentication

### Payment Processing:
- Stripe integration (testing mode)
- Connect for payouts
