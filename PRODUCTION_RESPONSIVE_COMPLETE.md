## Responsive Utilities

### CSS Utility Classes
```css
/* Typography */
.text-responsive        /* 0.875rem → 1.0625rem */
.text-responsive-sm     /* 0.8125rem → 0.9375rem */
.text-responsive-lg     /* 1rem → 1.25rem */
.heading-responsive     /* 1.75rem → 3.5rem */

/* Interactive Elements */
.btn-responsive         /* Adaptive button with touch targets */
.input-responsive       /* Adaptive input with 44px min height */
.touch-target          /* Min 44×44px touch area */

/* Spacing */
.spacing-responsive     /* gap: clamp(0.5rem, 1vw, 1rem) */
.spacing-responsive-lg  /* gap: clamp(0.75rem, 1.5vw, 1.5rem) */

/* Icons */
.icon-responsive        /* 1rem → 1.5rem */
.icon-responsive-lg     /* 1.25rem → 2rem */

/* Interactive Feedback */
.interactive-hover      /* hover:scale-105 + shadow */
.interactive-press      /* active:scale-95 */
.interactive-full       /* Both hover and press states */
```

### React Hooks
```typescript
// Screen size detection
const { isMobile, isTablet, isDesktop } = useScreenSize()

// Responsive values
const { buttonSize, iconSize, spacing } = useResponsiveSize()

// Responsive font
const { fontSize, lineHeight } = useResponsiveFont()
```

## Mobile-First Breakpoints

### Tailwind Breakpoints
- **Mobile**: < 640px (default, no prefix)
- **Tablet**: ≥ 640px (`sm:`)
- **Desktop**: ≥ 1024px (`md:` or `lg:`)

### Common Responsive Patterns
```tsx
// Grid Layouts
className="grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-4 gap-4"

// Button Sizes
className="h-10 sm:h-9 md:h-10 px-4 sm:px-3 md:px-4"

// Text Sizing
className="text-responsive text-sm sm:text-xs md:text-sm"

// Spacing
className="gap-3 sm:gap-2.5 md:gap-3 p-6 sm:p-5 md:p-6"

// Visibility
className="hidden lg:block"  // Desktop only
className="lg:hidden"         // Mobile/tablet only
```

## Table Responsive Pattern
All wide tables use ScrollArea for horizontal scroll on mobile:

```tsx
<ScrollArea className="w-full">
  <Table className="min-w-[800px]">
    {/* Table content */}
  </Table>
</ScrollArea>
```
